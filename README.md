# Hand Over

واجهة Hand Over بعد تحويلها إلى Next.js App Router وTypeScript.

## التشغيل المحلي

1. ثبّت Node.js 20.9 أو أحدث.
2. افتح الطرفية في هذا المجلد وشغّل `npm install`.
3. شغّل `npm run dev` وافتح `http://localhost:3000`.

لإنشاء نسخة إنتاج استخدم `npm run build`، ثم شغّلها عبر `npm run start`.

## بنية المشروع

- `app/`: صفحة App Router والتخطيط العام والتنسيقات.
- `components/HandOverApp.tsx`: واجهة الموقع وتفاعلاتها.
- `public/agency-logo.png`: شعار أمانة حفر الباطن.
- `backup/index.original.html`: نسخة احتياطية غير معدّلة من الصفحة الأصلية.
- `index.html`: الملف الأصلي محفوظ كما هو خارج مجلد التطبيق.

صفحة الدخول ولوحة الأحداث هنا نموذج واجهة فقط؛ لا يوجد تحقق فعلي من الحساب أو اتصال بقاعدة بيانات. بيانات النموذج تحفظ محليًا في المتصفح.
